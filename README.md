# Ли 力 Wok & Tea

Статический сайт кафе Li в Волгограде. HTML, CSS и JavaScript без серверной части. Публикуется в отдельном публичном репозитории через GitHub Actions → GitHub Pages.

## Локальный запуск

Node.js 22 или новее (в CI используется Node.js 24).

```powershell
npm ci
npm run dev
```

Открыть http://127.0.0.1:4173/. После изменения исходников обновить страницу.

## Проверки и сборка

```powershell
npm run check
npm test
npm run build
```

`check` проверяет синтаксис JavaScript, локальные ссылки, якоря и данные меню. Node tests проверяют повреждённое хранилище корзины, суммы, ограничения количества и текст заказа. Сборка копирует только `site/` в `dist/`.

В GitHub Actions дополнительно выполняются браузерные проверки Playwright на desktop и mobile: фильтры, поиск, корзина, сохранение после перезагрузки, валидация адреса, копирование, запрос столика, мобильная навигация, overflow, изображения и reduced motion. Скриншоты и отчёт доступны в артефакте `browser-checks` каждого запуска. Развёртывание начинается только после успешных проверок.

Для отдельного запуска браузерных тестов на своей машине:

```powershell
npx playwright install chromium
npm run build
npm run test:e2e
```

## Публикация

Workflow: `.github/workflows/pages.yml`. Push в `main` запускает проверки, сборку и публикацию; pull request запускает проверки без публикации. Источник Pages в настройках репозитория: GitHub Actions. Все локальные пути относительные, поэтому сайт работает под `/li-wok-tea/` без отдельного домена.

Сборка добавляет к URL основного CSS версию из хеша его содержимого. После изменения оформления браузер запрашивает новую версию, не смешивая обновлённые тексты со старыми стилями.

Обложка ссылки: `site/assets/social-cover-v2.jpg`, 1200 × 630, создана из реального первого экрана сайта. Для обновления после изменения главного экрана: `node scripts/social-cover.mjs <актуальный desktop-hero.png>`. Open Graph и Twitter Card ссылаются на JPEG и содержат его размеры. Кэш превью в мессенджерах управляется самим мессенджером; сайт не обновляет старые сообщения.

## Функции и границы

- 30 позиций меню, категории и поиск по всем блюдам.
- Корзина хранит только идентификаторы и количества, не адреса или имена.
- Самовывоз и доставка; сумма блюд рассчитывается по меню доставки Яндекс Еды.
- Кнопка копирования готовит текст; пользователь сам отправляет его в `@li_vlg_admin`. Сайт не отправляет сообщения и не утверждает, что заказ принят.
- Если доступ к clipboard запрещён, текст выделяется для ручного копирования.
- Запрос столика: дата, время, количество гостей, копирование. Автоматического подтверждения нет.
- Телефон, карта, маршрут, публичный канал и ссылка на реальные отзывы.
- Фотографии и шрифты хранятся локально. Единственный внешний встроенный ресурс: карта Яндекса. При недоступности карты есть прямая ссылка.
- Отсутствуют оплата, боты, серверные API и аналитика.
